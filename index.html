Adicionar novo imóvel

Preencha os dados abaixo. O imóvel aparece automaticamente na aba escolhida e fica salvo neste navegador.

Clique na ⭐ de uma foto para definir a foto de capa. Vídeos MP4/WebM direto do celular ou PC.

Como publicar para todos: no GitHub, abra o index.html → ícone de lápis ✏️ → procure (Ctrl+F) por COLE AQUI AS LINHAS → cole a linha copiada na linha abaixo daquela marcação → Commit changes. Em 1 minuto o imóvel aparece no site para todo mundo!

🗑 Para remover um imóvel publicado: apague a linha correspondente dele no index.html e faça o commit.

💡 Com GitHub Token configurado, a publicação é automática e atualizada em tempo real para todos (fotos, vídeos e remoção). Sem token, use o código manual acima.
